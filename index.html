LALinear Algebra
课程学习路径学习方法仓库说明
VISUAL · RIGOROUS · INTERACTIVE

让线性代数
变得看得见。

从一个向量开始，逐步理解矩阵如何变换空间、方程组如何确定解、特征方向如何显现，最后看见 SVD 如何拆解复杂变换。

核心问题Ax=b几何、代数与计算的交汇点

八个模块，一条完整学习路线

先建立几何直觉，再建立代数语言；先理解结构，再学习计算。每篇都有独立图示、公式推导、例题、交互实验和自测。

MODULE 01 · FOUNDATIONS

向量与线性组合

向量不只是数字列表；线性组合让我们描述可达的方向与位置。

哪些点可以由给定向量组合得到？ →
 MODULE 02 · TRANSFORMATIONS

矩阵与线性变换

矩阵的列记录基向量去了哪里，矩阵乘法记录变换的先后次序。

矩阵究竟在改变什么？ →
 MODULE 03 · SOLVING

线性方程组与高斯消元

把几何交点转成可执行的行变换，理解唯一解、无解与无穷多解。

为什么消元能找到交点？ →
 MODULE 04 · STRUCTURE

向量空间、秩与维数

列空间、行空间、零空间与左零空间揭示矩阵的完整结构。

一个矩阵揭示了哪些空间关系？ →
 MODULE 05 · GEOMETRY

行列式与体积

从单位正方形的面积变化，理解可逆性、方向翻转和体积缩放。

一个数字为什么能表示面积变化？ →
 MODULE 06 · INVARIANTS

特征值与特征向量

找到变换中方向不变的向量，用特征值描述沿该方向的伸缩。

哪些方向经过变换后仍然共线？ →
 MODULE 07 · PROJECTION

正交投影与最小二乘

当方程没有精确解时，寻找残差最小且满足正交条件的近似解。

如何找到离数据最近的解？ →
 MODULE 08 · DECOMPOSITION

奇异值分解与低秩近似

任何实矩阵都能拆成两次正交变换与一次轴向伸缩。

如何拆解一个复杂的线性变换？ →

知识之间如何连接

前四篇回答“矩阵能做什么、解在哪里、空间有多大”；后四篇回答“变换如何改变体积、哪些方向特殊、如何逼近与压缩”。

01–02 · 建立语言向量、组合、线性映射与矩阵
03–04 · 理解结构消元、秩、基、四个基本子空间
05–06 · 研究变换行列式、特征值与对角化
07–08 · 优化与分解投影、最小二乘、SVD

每个模块如何展开

01 · INTUITION

先问一个好问题

从学生已有经验出发，让抽象概念有具体的几何对象。

02 · VISUAL MODEL

让图形承担解释

箭头、网格、子空间和投影都对应明确的数学命题。

03 · MATHEMATICS

公式逐步推导

解释符号、维度、前提条件；不把公式当成需要背诵的结果。

04 · VERIFICATION

多路径交叉验证

通过代入、维数检查、几何解释和反例确认结论。
